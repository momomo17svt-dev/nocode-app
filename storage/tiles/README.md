# 地図タイル配置フォルダ（オフライン地図 方式②）

このフォルダはバックエンドが `/tiles/<種別>/{z}/{x}/{y}.<ext>` として配信します。
オフライン/LAN 環境でも地図を表示するため、ここに XYZ 形式のタイル画像を配置します。
背景地図は**種別ごとのサブフォルダ**に分かれます（pale=淡色 / std=標準 / photo=航空写真）。

## フォルダ構造
```
storage/tiles/
  pale/            ← 淡色地図（既定）
    13/7273/3225.png
  std/             ← 標準地図
    13/7273/3225.png
  photo/           ← 航空写真（JPG）
    13/7273/3225.jpg
```
`<種別>` が背景地図の種類、`{z}` がズーム、`{x}`/`{y}` がタイル座標です。
アプリの位置フィールド設定「背景地図」で、DL済みの種別を選べます。

## タイルの用意方法（インターネットに繋がる環境で実行）

バックエンドの補助スクリプトで、必要な範囲だけまとめてダウンロードできます。

```bash
cd backend
# 例: 東京駅周辺を ズーム13〜17 で取得（国土地理院 標準地図）
node scripts/download-tiles.mjs --bbox 139.74,35.65,139.80,35.70 --zoom 13-17
# = npm run tiles -- --bbox 139.74,35.65,139.80,35.70 --zoom 13-17
```

- `--bbox minLng,minLat,maxLng,maxLat` 取得する地理範囲
- `--zoom 13-17` または `--zoom 13,15,17` ズーム域
- `--source` 配信元テンプレート（既定は国土地理院 標準地図）
  - OSM 例: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`
- `--dry-run` 件数の見積りのみ

取得後 `storage/tiles/` ごと LAN サーバへコピーすれば、オフラインでも地図が出ます。
未取得の領域は空（グレー）で表示されます。範囲・ズームは欲張りすぎないでください
（ズームを1段上げるとタイル数は約4倍になります）。

## 注意（利用規約）
配信元の利用規約を必ず守ってください。
- 国土地理院: https://maps.gsi.go.jp/development/ichiran.html
- OSM タイル利用ポリシー（大量一括DL禁止）: https://operations.osmfoundation.org/policies/tiles/

社内/自前のタイルサーバがある場合は、アプリの位置フィールド設定「タイルURL」に
その URL テンプレートを指定すれば、このフォルダを使わず直接そちらを参照できます。
